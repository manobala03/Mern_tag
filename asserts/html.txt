4).Element---->1.An element defines structure/content.
              2.Example: <img>
              3.Elements are usually paired with opening and closing tags.
Attribute---->1.An attribute defines extra information about an element.
              2.Example: src="image.jpg" in <img src="image.jpg">
              3.Attributes are written inside the opening tag.

5).HTML entities are used to display reserved characters in HTML or insert symbols that can’t be typed easily.
example--&lt; = <
Why needed?
To avoid conflict with actual HTML syntax and to display special characters correctly.

6).Meta tags provide metadata about the HTML document. They are placed inside the <head> section
1.Set character encoding (<meta charset="UTF-8">)
2.Set viewport for responsive design (<meta name="viewport">)
ex--><meta name="description" content="This is a sample website.">

7).The best way to add images is using the <img> tag with proper alt text and optimized file formats.
ex--><img src="images/photo.jpg" alt="A description of the photo">
